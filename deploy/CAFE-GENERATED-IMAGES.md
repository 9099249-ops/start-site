# Иллюстрации для меню СТАРТ

23.09.2026. По запросу владельца созданы изображения для 31 позиции, у которых отсутствовали фотографии. Использован встроенный imagegen, по одному отдельному запросу на изображение. Настоящие изображения из предоставленного PDF сохранены.

Стиль: простая подача на деревянном столе у воды, естественный свет, белая посуда, предмет целиком в кадре. Напитки в бокалах без выдуманных этикеток брендов. Это сгенерированные иллюстрации, не документальные фотографии кухни; в меню добавлена краткая подпись о возможном отличии подачи.

- Полный набор запросов: `output/imagegen/cafe/prompts.json`.
- Соответствия исходных файлов генерации и позиций: `output/imagegen/cafe/generated.json`.
- Скопированные оригиналы: `output/imagegen/cafe/*.png`.
- Файлы сайта: `dist/assets/cafe-ai-*-v1-w480.webp` и `*-w960.webp`.
- Соответствия каталогу: `deploy/cafe-generated-map.json`.

Меню использует отложенную загрузку, адаптивный `srcset`, заданные размеры для предотвращения сдвигов. Публикация заполняет только пустое поле `image` по совпадающим ID и названию; цены, состав, стоп-лист, заказы и ранее добавленные фотографии сохраняются. Изменения каталога отражаются в audit log. Новых таблиц нет, перезапуск сервера не требуется. Перед публикацией делаются резервные копии файлов и SQLite; после проверяются HTTP/MIME/хеши обеих версий каждого изображения.

Скрипты: `deploy/prepare-cafe-generated-prompts.mjs`, `deploy/prepare-cafe-generated-assets.py`, `deploy/publish-cafe-generated.py`. Повторный запуск подготовки запросов сверяет наличие пустых фото в сохранённом `tmp/cafe-current.json`; это снимок до обновления.
