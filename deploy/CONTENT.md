# Content and SEO editor — 21 September 2026

Owner-only section at https://spotsup.ru/admin/#content-editor. Existing admin/station accounts and sessions are reused; station receives 403 on all content endpoints and preview. Content is stored in site_content (draft/published/revision) with previous published snapshots in content_versions and actor/action audit. Save never changes live content; preview requires admin auth, is noindex, and suppresses booking submission. Publish copies saved draft atomically; restore copies a previous snapshot into draft only. Revision checks reject stale saves/publications. Existing source HTML and design remain the rendering template; escaped content fields replace known baseline text. Do not change baseline strings casually without updating content-defaults.json/renderContent.

Editable: main heading and section/FAQ copy, main and station photos, four featured equipment photos, equipment names/descriptions/prices, special SUP prices/deposit, contact phone/Telegram, daily hours in half-hour steps. Stock counts, season boundaries, routes, individual equipment identifiers and game content are not CMS fields. Published prices drive the cards and booking estimate; published hours drive form options AND server booking validation. Existing rentals/payments are unaffected. Hours never cross midnight. Raster uploads JPEG/PNG/WebP up to 8 MiB stored with random filenames under /var/lib/start-site/media, not in checkout; no SVG/HTML or arbitrary paths. Validate declared type against signature, return fixed raster MIME with nosniff. No image resizing or deletion UI yet.

SEO: server-rendered title/description, index toggle (OFF by default), canonical apex URL, Open Graph title/description/image, Twitter large image card, verification values for Yandex/Google. Dynamic robots.txt and sitemap.xml (homepage only). Nginx global noindex header removed so owner toggle works; admin meta/preview headers remain noindex, game location remains noindex. /index.html redirects to canonical root. Does not register/search-submit property or install analytics. Search rankings/indexing are not guaranteed. No external tags/custom scripts accepted.

Backups: existing database backup includes drafts/history; daily script now also archives media alongside SQLite backup on same VPS. Before deployment code archive and nginx backup retained. Never restore whole production database over real rentals to roll back CMS.

Validation: 23 Node tests; local HTTP end-to-end verifies admin vs staff authorization, foreign origin rejection, raster upload/download, private draft preview, publish, price config, robots/sitemap. Browser verified editor fields, save and rendered preview including fleet. All fixture changes use isolated temporary database, not production.
