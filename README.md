# СТАРТ — сайт, админка и SUP-игра

Исходники станции проката **СТАРТ**: https://spotsup.ru/ . Снимок рабочей локальной версии от 25 сентября 2026 года.

## Структура

- `dist/` — сайт, меню кафе, административные интерфейсы, изображения и готовая игра в `dist/game/`.
- `server/` — Node.js API, SQLite, бронирование, прокат, кафе, закупка, сотрудники, зарплата, SMS Aero и Telegram; миграции и автоматические тесты.
- `game-src/` — полные исходники SUP-игры: TypeScript, Canvas, Vite, карта, тесты и скрипт импорта карты.
- `deploy/` — конфигурации Nginx/systemd для существующего сервера и проверяемая утилита исправления связей склада/прав.
- `start-print-agent/` — агент Raspberry Pi/CUPS для заказов кафе и отчётов смены; [подключение и результаты проверки](deploy/PRINT-INTEGRATION.md).

Базы клиентов, брони, пароли, ключи API, серверные секреты, журналы и резервные копии в репозиторий не входят. SQLite и опубликованный через редактор контент сохраняются отдельно на сервере. Этот репозиторий — исходный код, а не полная резервная копия данных работающей станции. История локальных экспериментальных публикаций не переносилась.

## Запуск сайта

Нужен **Node.js 24** со встроенным `node:sqlite`. Внешних npm-зависимостей у серверной части нет. HTML/CSS/JS сайта находятся непосредственно в `dist/`, отдельная сборка сайта не требуется.

Для обычного просмотра:

```sh
node server/server.mjs
```

Откройте http://127.0.0.1:4173/ . Без `BOOKING_DB` административные функции отключены.

Для изолированной демонстрации админки с временной базой и подменёнными исходящими SMS/Telegram:

```sh
node server/sms-demo.mjs
```

Демонстрационный адрес и тестовые данные входа будут напечатаны в терминале. Этот режим предназначен только для локальной разработки.

Для постоянной локальной базы создайте каталог `data`, скопируйте `.env.example` в `.env` и запускайте:

```sh
node --env-file=.env server/server.mjs
```

Создание первого администратора: передайте случайный одноразовый код из 64 шестнадцатеричных символов через stdin в `node --env-file=.env server/admin-bootstrap.mjs`, затем откройте `/admin/` и завершите первоначальную настройку. Секреты интеграций задаются только на сервере. Не используйте production-базу для тестирования.

## Игра

Готовая игра размещается по https://spotsup.ru/game/ . Исходники и подробное описание управления — в [game-src/README.md](game-src/README.md).

```sh
cd game-src
npm ci
npm test
npm run build
npm run dev
```

Новая сборка создаётся в `game-src/dist/`. Для обновления игры на сайте перенесите содержимое этой папки в `dist/game/` с сохранением структуры. Сам сайт при этом не требует пересборки. Геоданные OpenStreetMap сопровождаются отдельной лицензией [game-src/DATA-LICENSE.md](game-src/DATA-LICENSE.md).

## Проверки

Из корня репозитория:

```sh
node --test server/*.test.mjs
```

Для игры — `npm test` и `npm run build` из `game-src/`; сборка включает проверку TypeScript.

## Размещение

Рабочая система использует Node.js за Nginx и внешнюю SQLite-базу. Файлы в `deploy/` соответствуют существующей серверной схеме и требуют проверки путей, домена и сертификатов перед использованием на другом сервере. GitHub сам по себе не запускает backend; GitHub Pages не заменяет сервер бронирований и админки. Автоматическая публикация на production из этого репозитория не настроена.
