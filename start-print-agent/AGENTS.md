# Raspberry Pi, CUPS и доставка печати

Действует вместе с корневым `AGENTS.md`. Перед работой читать `README.md`, `../START-PRINT-REQUIREMENTS.md` и применимые `../deploy/PRINT-INTEGRATION.md` / `../deploy/PRINT-PROTOCOL-DRAFT.md`. Не считать исторические отчёты подтверждением нынешней физической печати.

## Роли и границы

- Luna прослеживает событие заказа/смены в `../server/print.mjs`, payload, `site_protocol.py`, очередь/попытки в `main.py`, CUPS и соответствующие тесты.
- Luna-исполнитель может править локальный макет талона, форматирование или ограниченный тест по плану. Изменение протокола, идентичности/дедупликации документов, восстановления после сбоя, инфраструктуры или внешнего сервиса эскалировать GPT-6.
- Талон кухни и фискальный чек являются разными документами/процессами. Изменение вида талона не разрешает повторную финансовую операцию.
- Сохранённые payload, ID задания/документа, очередь, outbox и история попыток должны сохранять совместимость. Display number 001–999 предназначен для человека; дедупликация не строится на нём.
- Не перепечатывать автоматически при неизвестном результате отправки в CUPS. Не очищать очередь или SQLite агента ради восстановления; не подменять pairing/database ID нового экземпляра молча.
- Raspberry Pi является отдельной установленной системой: копия `start-print-agent/` на сервере сайта сама по себе не доказывает версию активного агента. Luna проверяет фактическую службу/путь только в разрешённом scope.

## Проверки

Все тестовые данные должны быть отдельными от рабочей очереди и принтера. Из корня репозитория, используя доступный Python (на Linux обычно `python3`):

```sh
python -m unittest discover -s start-print-agent -p "test*.py" -v
```

Discovery включает `tests.py`, `test_protocol.py`, `test_network.py`, `test_customer_number.py`. README также содержит команду для установленных на Pi модулей; её окружение/каталог учитывать отдельно. Подмена CUPS и тестовый рендер проверяют код, но не бумагу, звук, сеть и реальный принтер.

Изменения общего номера/протокола проверять вместе с серверными тестами печати и кафе. Аппаратный тест, установка службы и изменение настроек требуют разрешения на соответствующие реальные действия. Уже выданное разрешение учитывать; рабочие заказы повторно не печатать.
