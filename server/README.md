# Сервер СТАРТ

Node.js 24, встроенный HTTP и SQLite. Основная точка входа — `server.mjs`.
Инструкции по запуску и настройке находятся в [корневом README](../README.md).

Интеграции SMS Aero и Telegram получают секреты из окружения сервера.
Тесты: `node --test server/*.test.mjs` из корня проекта.
