# СТАРТ — SUP по Ореховой бухте

Опубликовано: https://spotsup.ru/game/ . На главной spotsup.ru добавлен пункт «SUP-игра».

Рабочий браузерный MVP: реальная береговая линия, SUP с инерцией, один маршрут из пяти контрольных точек, пять звёзд, штрафы за столкновения, мини-карта, пауза, результат и локальные рекорды.

## Запуск

Нужен Node.js 22.12+ (для `npm test` — Node.js 22.18+ или 24 LTS).

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно http://localhost:5173.

```bash
npm test
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`. Её можно разместить на хостинге в `/game/`. Не открывайте `dist/index.html` через `file://`: ES-модули требуют HTTP. Карта, графика и звуки работают локально; во время игры внешние сервисы не вызываются.

## Управление

- Компьютер: W / ↑ — грести; A/D / ←/→ — поворот; пробел — усиленный гребок с запасом энергии; Esc или P — пауза.
- Телефон: джойстик слева задаёт направление, кнопка справа отвечает за греблю. Можно одновременно держать оба пальца. Отмена касания и потеря фокуса сбрасывают управление.
- В портретной ориентации игра просит повернуть телефон и ставит заезд на паузу. После поворота нажмите «Продолжить».
- Пройдите буи 1–5 по порядку. Пятый буй — финиш. Звёзды можно собирать в любом порядке. За столкновение добавляются 2 секунды; повторные штрафы ограничены задержкой 1,8 с. Времени на прохождение не ограничено.

## Что настроить перед размещением

1. **Точка станции подключена.** `station` в `src/data/map.json`: 55.973457, 37.663009, по ссылке владельца https://yandex.ru/maps/-/CXAXqRoX . Старт SUP находится рядом на воде; точка финиша также перенесена к станции. Исходная ссылка и географические координаты сохранены в конфигурации.
2. **Бронирование подключено.** `bookingUrl` в `src/data/config.json` ведёт на https://spotsup.ru/ — действующий сайт из проекта «Создание сайта Старт». Там кнопка «Забронировать» открывает форму с выбранным САПбордом. Это заявка сотруднику, бронь подтверждается отдельно. Отдельного URL, автоматически открывающего форму, на сайте нет.
3. **Проверить фирменные материалы.** Текстовый знак «СТАРТ», палитра, SUP и персонаж подготовлены для прототипа. Официальный логотип и брендбук не были предоставлены.
4. **Проверить на целевых телефонах.** Компоновка и обработчики ввода проверены в настольном браузере, в том числе при мобильных размерах. Реальные FPS, Safari/iOS, жесты двумя пальцами и звук на физических устройствах требуют проверки на этих устройствах.

## Карта и координаты

Берег и 17 пирсов получены из OpenStreetMap. Это локальные векторные данные, а не спутниковое изображение или вымышленная береговая линия. Стилизованный лес — процедурное оформление суши, не геоданные о растительности. Острова не дорисовывались: исходный водный полигон не содержит внутренних колец; движок поддерживает их при замене карты.

- `src/data/map.json`: габариты, географические границы, полигоны воды, пирсы, станция, старт, препятствия и зоны.
- `src/data/routes.json`: контрольные точки, радиусы попадания, звёзды.
- `src/data/config.json`: бронирование, цвета доски, жилета и персонажа.
- `scripts/osm-reservoir.xml`, `scripts/osm-local.xml`: исходные снимки OSM от 21.09.2026.
- `scripts/import-map.py`: воспроизводимый импорт снимков, только стандартная библиотека Python. Пересоздаёт `map.json` **и** `routes.json`; пользовательские изменения координат следует сначала перенести в скрипт.

Проекция локальная, ось X направлена на восток, Y — на юг. В этой карте 3 игровых единицы соответствуют 1 метру. Для новых координат:

```text
x = (longitude - bounds.west) × 111320 × cos(midLatitude) × 3
y = (bounds.north - latitude) × 111320 × 3
```

Мели, запретная зона, буи, лодка и маршрут являются игровыми, а не гидрографическими или навигационными данными. Детали источников и лицензия — в `DATA-LICENSE.md`.

## Архитектура

TypeScript + Vite + Canvas 2D. Phaser в ТЗ указан как предпочтительный, а Canvas — допустимый; для этой небольшой игры выбран Canvas, чтобы не загружать библиотеку движка. Сборка не имеет runtime-зависимостей, внешних шрифтов, тайлов или аудиофайлов.

- `Simulation.ts` — независимая физика с фиксированным шагом 1/60 с, береговые столкновения, штрафы, маршрут и бонусы.
- `Renderer.ts` — один кешированный слой ландшафта, видимые волны, SUP, след, частицы, следящая камера и мини-карта. DPR ограничен 2.
- `Traffic.ts` — катер и три сапбордиста на замкнутых маршрутах, плавный поворот, след на воде; пауза останавливает их вместе с игроком. Позиции, скорости и цвета находятся в `map.json`, секция `traffic`. Столкновения учитывают относительное перемещение обоих объектов и дают +2 секунды даже при неподвижном игроке.
- `Controls.ts` — клавиатура и независимые Pointer Events для двух пальцев.
- `Audio.ts` — процедурный фон воды и короткие звуки через Web Audio, активируемые после действия пользователя.
- `Score.ts` — localStorage, личные и дневные рекорды, события аналитики.
- `main.ts` — HTML-интерфейс и переходы меню → игра → пауза / финиш.

Общая таблица рекордов отсутствует: «Мой рекорд сегодня» относится только к этому браузеру. При запрете localStorage игра продолжает работать и сообщает о невозможности сохранения. Фоновая музыка не добавлена; есть фон воды, гребки и звуки событий.

## Встраивание

Можно разместить `dist/` в `/game/` или встроить страницу:

```html
<iframe src="/game/" title="SUP-прогулка по Ореховой бухте"
  style="width:100%;height:850px;border:0" allow="fullscreen"></iframe>
```

H1, описание, управление и CTA выполнены обычным HTML. В Canvas находится только мир игры. Высоту iframe подберите под макет сайта. Внутри cross-origin iframe сохранение зависит от политики браузера.

## Аналитика

Игра ничего не отправляет третьим сторонам. Сайт может подписаться на события:

```js
window.addEventListener('start-sup:analytics', ({ detail }) => {
  console.log(detail.event, detail);
  // Здесь можно подключить собственную Метрику или аналитику.
});
```

События: `game_open`, `game_start`, `checkpoint`, `star_collected`, `game_finish`, `replay`, `booking_click`. Для `game_open` установите обработчик перед загрузкой игрового модуля. В iframe подписка устанавливается в окне игры; пересылку в родительский сайт нужно подключить отдельно.

## Проверки

`npm test` запускает проверки: реальные координаты на воде, прохождение полного маршрута без телепортации (69,72 с, 5 звёзд, 0 столкновений), порядок точек, инерция, штрафы, берег/пирсы/острова, зоны, энергия и сохранение результатов с отказами хранилища. Дополнительные проверки покрывают движение всех NPC по воде в течение 240 секунд, наезд катера на неподвижного игрока и полное прохождение с трафиком (74,20 с, 5 звёзд, 1 столкновение).

При запущенном dev-сервере `/tests/controls.html` выполняет девять браузерных проверок клавиатуры, двух одновременных указателей, отмены касаний и потери фокуса. Захват указателя в этой тестовой странице заменён тестовым объектом; это проверка логики обработчиков, а не замена тесту на настоящем телефоне. Страница не включается в production-сборку.

Результаты сборки и проверки интерфейса записаны в `VERIFICATION.md`.
