СТАРТ: восстановление или замена ESP32, прошивка 1.1.3

Подходит классическая ESP32 Dev Module (ESP32-D0WD), 4 МБ flash.
Не подходит для ESP32-C3, S2, S3 и других чипов: им нужен свой образ.

1. На компьютере с уже установленной Arduino IDE скачайте «Полная прошивка для замены ESP32».
2. Подключите новую плату USB-кабелем с передачей данных. При необходимости установите официальный драйвер её USB-UART.
3. Закройте Serial Monitor. Узнайте номер COM-порта в диспетчере устройств.
4. В PowerShell выполните команды ниже. Они используют esptool из установленного ESP32-пакета Arduino, не требуют установки нового программного обеспечения.

$batteryTool = Get-ChildItem -LiteralPath "$env:LOCALAPPDATA\Arduino15\packages\esp32\tools\esptool_py" -Filter esptool.exe -Recurse | Select-Object -First 1
$batteryPort = Read-Host 'COM-порт ESP32, например COM4'
$batteryImage = Join-Path $env:USERPROFILE 'Downloads\START-ESP32-1.1.3-recovery.bin'
if ((Get-FileHash -LiteralPath $batteryImage -Algorithm SHA256).Hash.ToLowerInvariant() -ne '3b3f6b39e68bb71182fad5b8d9257afa1fe80957e933dbf947a5931619649a19') { throw 'Контрольная сумма файла не совпадает' }
& $batteryTool.FullName --chip esp32 --port $batteryPort --baud 460800 write-flash 0x0 $batteryImage

Если файл сохранён не в «Загрузки», измените путь $batteryImage. Если подключение не начинается, удерживайте кнопку BOOT при начале загрузки и отпустите после соединения.
Полная прошивка создаёт исходную разметку flash и может удалить прежние настройки платы. Для обычного обновления действующей ESP32 используйте обновление по Wi-Fi в админке.

5. Откройте Serial Monitor Arduino IDE: 115200 бод, окончание строки «Новая строка».
6. В админке откройте существующий профиль нужного аккумулятора. Не создавайте новый аккумулятор только из-за замены ESP32: так сохранится история. Нажмите «Выпустить новый ключ ESP32» и сохраните показанный ключ для следующего шага; старый ключ перестанет работать.
7. Отправьте по USB три команды (вместо заглавных слов подставьте свои данные):

wifi ИМЯ_СЕТИ|ПАРОЛЬ
server https://spotsup.ru|ID_ПРОФИЛЯ|НОВЫЙ_КЛЮЧ_ESP32
monitor BLUETOOTH_АДРЕС_АККУМУЛЯТОРА

Эти значения не входят в универсальную прошивку. Не передавайте ключ и пароль посторонним. Команда status показывает связь без вывода пароля или ключа.
8. Убедитесь, что в админке появились свежие показания, после чего переставьте USB в адаптер 5 В.

Wi-Fi и последующие подписанные обновления доступны в «Настройки → Состояние аккумуляторов → Состояние и сведения ESP32/BMS → Wi-Fi и обновление ESP32».
При смене Wi-Fi модуль пробует новую сеть до двух минут. Если не удаётся отправить защищённый пакет на сервер, он возвращается к прежней сети. После полного отключения от старой и новой сети удалённые команды недоступны; восстановление выполняется по USB.
